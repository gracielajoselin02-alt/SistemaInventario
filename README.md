 Simulación y análisis de señales con la Transformada de Fourier

 Descripción
Este proyecto utiliza Python para generar tres señales: un pulso rectangular, una función escalón y una señal senoidal.

 Objetivo
Analizar las señales en el dominio del tiempo y de la frecuencia utilizando la Transformada de Fourier.

Herramientas utilizadas
- Python
- NumPy
- Matplotlib
- Google Colab

 Desarrollo
El programa genera las tres señales, calcula la Transformada de Fourier mediante `np.fft.fft()` y muestra gráficas de las señales, la magnitud y la fase de sus espectros.

 Resultados
Las gráficas permiten comparar las señales en el dominio del tiempo y observar las frecuencias presentes en cada una.

 Cómo ejecutar el código
1. Abrir el archivo `simulacion_fourier.py` en Google Colab o en un entorno compatible con Python.
2. Instalar las librerías necesarias con `pip install numpy matplotlib`, si aún no están instaladas.
3. Ejecutar el programa para generar las gráficas.

Conclusión
La Transformada de Fourier permite comprender las características de las señales y estudiar su contenido de frecuencia, con aplicaciones en audio, comunicaciones y sistemas electrónicos.
